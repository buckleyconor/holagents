# Learning arc (plan level)

Does the module sequence teach a coherent skill? Score each criterion
1–5 using the anchors in the scoring guide.

## Criteria

### progression

The sequence follows observation → guided → independent: early modules
walk through with explicit direction, later modules give more
independence (fewer hand-holding steps, open-ended checks).

### one-concept-per-module

Each module's goal centers on ONE core concept; modules that bundle two
unrelated concepts score low.

### no-concept-islands

No module assumes vocabulary or state introduced only in a non-adjacent
module; early-module vocabulary is reused later (not re-explained).

### difficulty-ramp

Difficulty rises gradually; no module jumps far beyond what the prior
modules established (at module 2, judge against module 1; flag sudden spikes with the module in the
finding).
