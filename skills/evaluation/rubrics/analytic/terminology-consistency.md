# Terminology consistency (guide level)

Whole-guide language discipline at `/hol-review-guide`. Score each
criterion 1–5.

## Criteria

### product-names

Product and feature names are spelled the same way everywhere and
match the product profile in ~/.holagent (first mention may expand,
subsequent use stays constant).

### no-synonym-drift

The same object/feature is never given two names across modules
(cite both spellings and their module locations in the finding).

### credential-terms

Demo credentials appear verbatim every time (identical username,
password, host:port) — a single rephrased occurrence is a drift.

### house-terms

House terminology is used: "module" (not "challenge/phase/lesson"),
"checkpoint", "Lab Credentials", "Table of Contents".
